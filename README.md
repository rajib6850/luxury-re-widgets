# Luxury Real Estate Widgets (Elementor Addon)

A high-performance, ultra-luxury Elementor widget suite designed for high-end luxury real estate agencies and estates.

## Features
- **LRE - Luxury Navigation Bar**: Seamless transparent, light, and dark header with 5-column fullscreen side drawer.
- **LRE - Luxury Hero Banner**: Ken Burns slider, responsive full-bleed video backgrounds, and cinematic masked headline reveals.
- **LRE - Luxury About**: Editorial split showcase with responsive typography.
- **LRE - Luxury Services**: Curated concierge and advisory service cards.
- **LRE - Luxury Featured Properties**: Interactive multi-card carousel with capsule dots and zero-pink circular navigation arrows.
- **LRE - Luxury Testimonials**: High-touch social proof slider.
- **LRE - Luxury Communities**: Architectural neighborhood showcase carousel.
- **LRE - Luxury CTA & Footer**: High-converting lead generation and footer navigation suite.
