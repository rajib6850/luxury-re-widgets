26 handcrafted, editorial-grade Elementor section widgets for building high-end luxury real estate websites block by block. By Digitize Growth.

== Description ==

**Luxury Real Estate Widgets** by [Digitize Growth](https://digitizegrowth.com/) gives you 26 handcrafted, editorial-grade Elementor section widgets to build stunning luxury real estate websites block by block.

All widgets are found under the **"Luxury Real Estate Widgets"** category inside the Elementor panel.

== Installation ==

1. Upload the `luxury-re-widgets` folder to `/wp-content/plugins/` or install via **Plugins > Add Plugin > Upload Plugin**.
2. Activate the plugin via **Plugins > Installed Plugins**.
3. Make sure **Elementor** (free) is installed and activated.
4. Open any page in Elementor and find the widgets under **"Luxury Real Estate Widgets"** in the panel.
